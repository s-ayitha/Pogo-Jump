# Hack-Club-Haven
Nick N. and Suhreeth A's Hack Club Haven game.

Pogo Jump: An endless pogo-stick platformer game requiring extreme precision and vigilance.
Players automatically bounce off platforms and must control their angle mid-air to modify their trajectory.

The goal is to climb as high as you can and beat your high score!

Controls: L/R arrow keys (L rotates you counterclockwise, R rotates you clockwise)

Features:
Projectile motion calculations to control movement of the player
Different platform types and obstacles
Infinite/repeating generation
Rebound walls and launch pads
High score tracking


Running the Project:

Install Godot 4.7.2.

Clone this repository:

git clone https://github.com/s-ayitha/Pogo-Jump.git

Open Godot.

Import the project by selecting its project.godot file.

Open the project and run the main scene.
